# Quaternius Ultimate Crops — Reference Record R1

Status: active reference for vegetable baseline; raw pack is not vendored.

## Source

- Author: Quaternius
- Pack: Ultimate Crops Pack / LowPoly Crops Pack
- Official page: `https://quaternius.com/packs/ultimatecrops.html`
- Public mirror/reference page: `https://opengameart.org/content/lowpoly-crops-pack`
- Pack date: January 2020
- Declared contents: 102 models, 5 growth stages, FBX / OBJ / Blend
- License: CC0 / Public Domain

## Role in Eric's Garden

Use as:

- multi-stage silhouette reference;
- juvenile/mature proportion reference;
- possible geometry/organ donor when a source mesh can be ingested cleanly;
- comparison source during crop review.

Do not treat the pack as the only botanical truth. Real crop references remain necessary where the stylized pack simplifies an identity-critical feature.

Important current examples:

- carrot foliage must read as fine divided foliage and the mature orange root should expose only a restrained shoulder above soil;
- pumpkin may use reference leaf/fruit proportions, but Eric's Garden keeps one primary fruit attached to the home plot while vine/leaves can spread outward;
- species scale is normalized to the existing Eric's Garden bed/plot frame rather than copied from arbitrary source coordinates.

## Repository boundary

The raw 13.4 MB ZIP/source pack is an external asset and is not committed wholesale. The current connector execution surface could verify the public ZIP and license but could not ingest the binary archive directly. R1 therefore uses project-authored procedural runtime geometry grounded by the reference.

If individual Quaternius meshes are later imported, normalize them to the crop frame, retain only the needed runtime subset, and record the exact source file/mesh identifiers here or in the species packet.
